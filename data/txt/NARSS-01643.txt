AI is evolving fast. You might have known that there are AI powered tools for various use cases such as GenAI - ChatGPT, image generation- DALL-E, MidJourney etc
 
Below are the Security Guidelines for using Generative AI tools:
 
DO’s:

	•	Being cautious of providing any data to GenAI as the chat input and history will become publicly available similar as posting anything in the internet.
	•	Explore or test GenAI with public or dummy data.
	•	Do use the genuine and official web or API version.
	•	Be vigilant on any phishing scams claiming itself to be genuine GenAI Services
	•	Do aware of any latest development, trends and hacking news of emerging GenAI technology.

Don’ts:

	•	Do not input or paste any personal information as dialogue into GenAI.
	•	Do not install any browser plug-in clamied itself to be GenAI unless being throughly assessed 
	•	Do not install any third parties mobile apps or web claimed itself to be GenAI unless being throughly assessed and evaluated
