I ordered a 256gb Samsung SD Card(₹1514) from Flipkart and it came a day early while I wasn't home so the security guard took it. 
When I came home and checked the package I noticed the model number didn't match and the details printed on packaging didn't match the ones printed on memory card (visible through plastic). So I called FK Customer care where they created a return request which later got rejected by seller citing that it was a open box delivery and product was intact while delivery. I called again, they created a return request again but same outcome. 
So I took a video of the package while cutting it open and inserting the SD card in my laptop and running the Samsung authentication tool which showed the result mentioning that it was indeed a fake card and mailed it to flipkart grievance team. Upon no response I called FK CC again where the executive saw the mail while on call, saw the video and created another return request but lo and behold again rejected for same reason. 
So feeling helpless I lodged a grievance on national consumer helpline and attached the screenshot from Samsung SD Card tool (since it did not allow me to post video) and flipkart there closed the grievance saying the same thing again. 
Now what should I do?
