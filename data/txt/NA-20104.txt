# Policy Water cooler

We cover the policies and other news that concerns the Indian government and citizens en masse here.

- Detailed Report on how AADHAAR data hack incident was carried out by Abhinav Srivastav [[AltNews](https://www.altnews.in/gois-national-informatics-centre-also-culpable-abhinav-srivastavs-aadhaar-data-hack-inciden)]

*Ed Note:* NIC really failed on the basic security checklist for their API. Reusing/piggy-backing on unrelated interfaces, not using https, Weak authentication through a fixed secret; you name it, they had it. It's not a surprise to see someone get into the system so easily. The third party services for AADHAAR are really the bane of the whole system and any system is only as secure as the weakest link.

- National Cyber Coordination Centre made operational: IT Mininstry [[IE](http://indianexpress.com/article/india/cyber-coordination-centre-made-operational-it-mininstry-4789272/)]

*Ed Note:* It remains to be seen whether NCCC is going to be for national security or will start an ever-pervasive and intrusive surveillance of Indian citizens' internet activity.

# World

This section takes a look at the top security news around the world which impact most of us.

**[Malware in the npm registry](http://blog.npmjs.org/post/163723642530/crossenv-malware-on-the-npm-registry)**

Beware of using packages even from "trusted" repositories like npm (node package manager). A malicious user uploaded packages with names very close to popular packages, which uploaded the system's environment variables to a remote server on being installed. This sets back the js community even more than the [leftpad](https://www.theregister.co.uk/2016/03/23/npm_left_pad_chaos/) fiasco that happened last year.
